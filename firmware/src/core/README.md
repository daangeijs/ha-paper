Pure C++17, no Arduino includes (ArduinoJson only in `ha_stream`, the HA event → entity mirror step). Compiled for device and for `pio test -e native`.
Owns: config model + YAML parse/validate/serialize (parity with spec/test-vectors), entity store, severity,
layout rects, paging, region diff, refresh policy, network-health decisions (`net_policy`: HA backoff jitter, Wi-Fi escalation, heap guard), power decision (`power.h`), glance wakes (`glance.h`: snapshot diff, wake step, Wi-Fi cache, first-boot count, the RTC record), persisted-state schema migrations (`migrate.h`), Improv Wi-Fi serial frames + device session (`improv.h`), PUT /settings key + POSIX tz checks (`settings_api.h`), the link-page HA address rules (`ha_address.h`), history tile bucketing / scale / axis (`history.h`, eink-ha-os#268) and chart geometry (`history_chart.h`, eink-ha-os#270), agenda / next tile events, scanner and fetch plan (`agenda.h`, eink-ha-os#316), the EN/NL string table (`strings.h` + generated `strings_gen.h`, eink-ha-os#98). Device-only code lives in src/hw, src/net, src/app.
