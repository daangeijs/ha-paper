# Deviations from the emulator (UI runtime + core)

Reference: `Main.dc.html` of the original design handoff. The `handoff/` folder was removed on 2026-10-16 (last
commit with it: `c7393ae`); this file stays as the record of where and why the firmware differs from that design and
from the emulator. Everything not listed here is meant to behave identically. Config parsing (`core/config.cpp`) has no deviations: messages, line numbers and quirks (cs: 0 accepted,
CRLF breaks `app:`/`title:` lines, index-like keys first in `toYaml`) are 1:1 and checked by
`test/vectors/config.json` (generated from the emulator's own `parseYaml` by `tools/gen_config_vectors.mjs`) and
`spec/test-vectors/config/*.json`.

One file per topic in [`deviations/`](deviations/): `NNN-slug.md`, NNN = the issue number (`000` = no issue).
A new deviation is a new file whose first line is its title (`# <topic> (issue #N)`); the list below is written
by `make deviations` and `make test` fails when it is stale.

The table of smaller differences from the emulator is
[`000-emulator-parity-table.md`](deviations/000-emulator-parity-table.md); change a row there only when you change
that behaviour.
